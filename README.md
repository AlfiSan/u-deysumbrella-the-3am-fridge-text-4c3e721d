Entry for the [make.fun](https://make.fun) bounty **The 3AM Fridge Text**: a program that writes the one line a smart fridge would text its owner at 3am.

`main.ts` writes a single 89-character line to `/output/entry.txt`, with no trailing newline:

> The thing in the back expired in March. It has started a family. Please stop ignoring it.

Run it with Node 22+: `node main.ts` (or `OUTPUT_DIR=/tmp/out node main.ts` to test locally).
